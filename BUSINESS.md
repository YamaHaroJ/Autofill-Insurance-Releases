# Autofill

Autofill is free life-insurance application workflow software designed to help insurance agents organize customer information and complete applications more efficiently.

## Cloud Listener

Cloud Listener is an optional AI-assisted call transcription service for Autofill. It is designed to improve transcription accuracy while reducing local computer CPU usage, including on Intel Macs.

### Pricing

- Core Autofill software: Free
- Cloud Listener: $1.50 per hour of active cloud transcription
- Minimum prepaid credit purchase: $5
- No subscription required
- Users can add additional prepaid credit at any time

## Billing

Cloud Listener uses prepaid usage credit. Credit is consumed only while Cloud Listener is actively transcribing. If prepaid credit runs out, the user can add more credit or continue using the free local listener.

## Refunds

Requests for refunds of unused prepaid Cloud Listener credit may be reviewed on request. Used transcription time is non-refundable.

## Support

Support is available for billing and technical issues related to Autofill and Cloud Listener.

## Privacy

Autofill processes information needed to provide its software and optional cloud transcription features. Cloud transcription may transmit call audio or transcript data to third-party AI infrastructure used to provide the service. Users are responsible for obtaining any consent required for recording or transcribing calls and for complying with applicable laws and workplace requirements.

## Terms

Autofill is provided as productivity software for insurance workflows. Users remain responsible for reviewing application information for accuracy before submission and for complying with carrier, regulatory, privacy, and consent requirements.
